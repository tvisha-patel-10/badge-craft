# 🏷️ Badgecraft

> *Make your mark, literally.*

**Badgecraft** is a digital name card maker. Design your own badge — pick a name, a title, stickers, colors, icons, whatever feels like "you" — and get it as a shareable png from your visit.

---

## 🕹️ How to Use

1. **✍️ Design** — Enter your name, pick a title/role, and customize stickers and colors
2. **👀 Preview** — Watch your badge come together in real time as you tweak it
3. **📸 Export** — Download your badge as an image, ready to share or save
4. **🔗 Share** — Post it, send it, or just keep it as a little proof you stopped by

---

## ✨ Features

- **Real-Time Preview** — Every change updates instantly, no "generate" button required
- **Fully Customizable** — Colors, icons, and layout options to make it genuinely yours
- **One-Click Export** — Download a clean PNG, ready to share anywhere
- **No Account Needed** — Design and download in seconds

---

## 🚀 Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/tvishapatel/badgecraft.git
cd badgecraft

# 2. Install dependencies
npm install

# 3. Start designing
npm run dev
```
